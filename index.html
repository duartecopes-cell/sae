Flujo real

Una ruta simple para practicar sin perderse.

La interfaz ahora explica solo lo que el sistema ya hace: ingresar, revisar la historia del caso, entrar al chat de entrevista y finalizar con el reporte.

01

Login del nivel

El usuario registra sus datos en la pantalla existente de Básico, Avanzado o Experto.

02

Historia del caso

El sistema muestra el contexto o expediente que ya alimenta la entrevista.

03

Chat de entrevista

La sala conserva las preguntas, respuestas, micrófono cuando está disponible y generación de reporte.
